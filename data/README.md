# Demo / seed data

CSVs that seed the B2BAgg Dev environment, plus the mock supplier feeds that
drive the `fetch-supplier-feed` Azure Function. Loaded by
[`scripts/seed-via-az-token.py`](../scripts/README.md).

## Seed CSVs (`data/seed/`)

| File | Rows | Purpose |
|---|---|---|
| `region.csv` | 7 | Russian federal districts + climate zone. |
| `supplier.csv` | 3 | Suppliers with mixed tier / trust score, each with a feed endpoint. |
| `warehouse.csv` | 6 | Regional distribution centres (city → federal district), with capacity — the M-4 analytics grain. |
| `canonicalproduct.csv` | 36 | Canonical tire catalog: brand/model/size/season + SKU-engine discriminators (`homologation`, `runflat`, `extraload`, `canonical_key`). |
| `supplieroffer.csv` | 201 | Raw supplier offers: `raw_sku`, `raw_name`, price, stock, `warehouse_city`, `lead_time_days`. |

> Load order matters (lookups): region → supplier → warehouse → product → offer.
> Offers bind to a warehouse by matching `warehouse_city`; the city text is kept
> as a denormalized cache alongside the `b2b_warehouse` lookup.

## AI Builder training data (`data/ai-builder/`)

| File | Rows | Purpose |
|---|---|---|
| `sku-training-data.csv` | 180 | Labeled `Text,Label` pairs for the AI Builder Custom Text Classification model (generated by `scripts/gen-training-data.py`). |

## Mock supplier feeds (`data/feeds/`)

Three deliberately **heterogeneous** schemas (EN / RU / pseudo-XML-as-JSON) that
exercise the SKU normalization pipeline.

| File | Schema |
|---|---|
| `feed-en.json` | Supplier A — English/normalized field names. |
| `feed-ru.json` | Supplier B — Russian field names. |
| `feed-xml.json` | Supplier C — flattened pseudo-XML structure. |
| `feed-supplier-{en,ru,xml}/feed.json` | The same three feeds in the per-container `{container}/feed.json` layout the Function/Blob expects (see PROGRESS QUIRK #7). |

> **Live vs. seed counts**: a freshly seeded Dev has exactly the row counts above.
> The live Dev environment may show more `b2b_supplieroffer` rows (e.g. 262) once
> the supplier-sync flow has run — that's seed (201) plus flow-synced records.
